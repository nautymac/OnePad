# 3D One 컨트롤러(OnePad) + Azahar — PC 재설치 가이드

마지막 정리: 2026-11-07. 이 폴더(`D:\OneDrive\AI\ClaudeCode\OnePad`)만 있으면 전부 복원된다.
한 줄 요약: **`OnePad-Setup-x.y.z.exe`(GitHub Releases 또는 OneDrive `dist`) 실행 → 재부팅.** 설치기가 HidHide·usbip-win2·AutoHotkey·Azahar를 내려받아 설치하고 로그온 작업까지 등록한다.
이 PC 전용 `OnePad-Setup-x.y.z-personal.exe`는 Azahar 설정·세이브까지 복원한다(배포 금지). `toolsSetup-OnePad.ps1`은 같은 일을 하는 스크립트 버전(예비).

## 1. 무엇이 어떻게 동작하는가 (왜 이 구성인지)

| 구성 요소 | 역할 | 없으면 생기는 일 |
|---|---|---|
| `bin\onepad.exe` (트레이 상주, 로그온 작업 `OnePad`) | 3D One의 벤더 HID 리포트를 읽어 ① 가상 **Steam Deck 컨트롤러**(USB/IP, 28DE:1205)로 Steam에 보여 주고 ② 데스크톱에서는 터치패드=마우스, 백버튼=좌/우 클릭으로 바꾼다 | 터치패드·백버튼 기능 없음 |
| usbip-win2 0.9.8.1 (`C:\Program Files\USBip`) | 가상 Deck 장치를 Windows에 꽂는 전송 드라이버 | Steam이 Deck을 못 봄 |
| HidHide 1.5.230 | 실제 3D One Xbox 패드를 Steam/게임에서 숨김(OnePad만 봄) | Steam이 실제 패드를 2P로 잡아 같은 버튼이 두 번 들어감(우선순위 설정 무효, "A 누르면 오버레이" 류 증상) |
| `%LOCALAPPDATA%\OnePad\onepad.ini` | 모든 설정. 패키지 `config\onepad.ini`가 확정본 | 기본값으로 동작(대부분 같음) |
| `D:\Azahar\azahar-launch.exe` | Azahar를 `SDL_JOYSTICK_WGI=0`, `SDL_JOYSTICK_HIDAPI_STEAMDECK=0`으로 실행하는 래퍼 | Azahar가 창 없이 멈춤(SDL 내부 교착) |
| Steam 비Steam 항목 "Azahar" | Azahar를 Steam Input 게임 설정으로 쓰기 위함 | Steam 데스크톱 레이아웃이 B=Space, X=PageUp 키를 만들어 바인딩이 꼬임 |

라우팅 규칙(onepad.ini `[deck] pads_to_steam=games_only`, `buttons_to_steam=games_only`):
- **Steam 게임 또는 Steam 창이 앞**: 패드·백버튼·자이로·버튼·스틱·트리거 전부 Steam 매핑. OnePad는 손 뗌.
- **그 외(데스크톱, 비Steam 앱)**: 패드=마우스(탭=클릭, 두 번 탭=더블클릭), 왼쪽 백버튼=왼클릭, 오른쪽 백버튼=우클릭. 가상 Deck에는 Steam/QAM 버튼만 전달.
- 탭 클릭은 Steam에서도 통한다(탭 펄스에 압력을 실어 보냄). Steam 설정에서 트랙패드 "클릭"에 마우스 좌클릭, "터치"는 비움.

## 2. 재설치 절차

### 설치기(권장)
1. Steam을 `D:\Steam`에 설치하고 로그인해 둔다.
2. `OnePad-Setup-1.0.0-personal.exe`(OneDrive `OnePad\dist\`)를 실행한다. 구성 요소: OnePad 본체, HidHide, usbip-win2(필수), Azahar + Steam 등록, AutoHotkey 단축키, AstraDepth3D 자동 시작, 개인 Azahar 설정·세이브 복원.
3. 재부팅. 설치 경로는 `C:\Program Files\OnePad`(로그온 작업 `OnePad`가 이 경로를 가리킴), 설정은 `%LOCALAPPDATA%\OnePad\onepad.ini`.
4. 설치기 다시 만들기: `ISCC.exe installer\OnePad-Setup.iss`(공개용, 2 MB, 설치 때 내려받음), `ISCC.exe /DPERSONAL=D:\OneDrive\AI\ClaudeCode\OnePad\personal installer\OnePad-Setup.iss`(개인용). Inno Setup은 `D:\DevTool\InnoSetup`.

### 스크립트(예비)
1. Windows 설치 후 OneDrive 동기화로 이 폴더가 `D:\OneDrive\AI\ClaudeCode\OnePad`에 오게 한다. (경로가 바뀌면 로그온 작업의 실행 경로도 바뀌므로 그대로 두는 게 편하다.)
2. Steam을 `D:\Steam`에 설치하고 한 번 로그인한다(userdata 폴더가 생겨야 Azahar 항목을 넣을 수 있다). Azahar 설정 자체는 Steam 클라우드에서 돌아온다.
3. 3D One 컨트롤러가 연결된 상태에서 **관리자 PowerShell**:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   D:\OneDrive\AI\ClaudeCode\OnePad\Setup-OnePad.ps1
   ```
   옵션: `-SkipAzahar`, `-SkipSteamShortcut`(Steam 종료가 싫을 때), `-ForceConfig`(ini 덮어쓰기), `-NoReboot`.
4. 재부팅한다. HidHide 필터는 재부팅 후에야 Xbox 스택에 붙는다(재부팅 전엔 Steam이 실제 패드를 계속 본다).
5. 재부팅 후 Steam → 설정 → 컨트롤러에 **Steam Deck 컨트롤러 하나만** 보이면 끝. 3D One이 같이 보이면 Steam을 한 번 더 재시작(아래 함정 참고).

### 수동으로 할 때(스크립트 없이)
- HidHide: `winget install --id Nefarius.HidHide --exact` (또는 `installer\HidHide_1.5.230_x64.exe`)
- usbip-win2: `installer\USBip-0.9.8.1-x64.exe` (Inno Setup, `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`)
- `config\onepad.ini` → `%LOCALAPPDATA%\OnePad\onepad.ini`
- `bin\onepad.exe` 한 번 실행 → 로그온 작업 자동 등록(HidHide 화이트리스트 등록·숨김도 자동)
- Azahar: `installer\azahar-windows-msys2-2126.1.zip`을 `D:\Azahar`에 풀고 `bin\azahar-launch.exe` 복사, 바로가기는 래퍼로, Steam 항목은 `tools\Add-SteamShortcut.ps1 -Name Azahar -Exe D:\Azahar\azahar-launch.exe -Icon D:\Azahar\azahar.exe`

## 3. 검증 (관리자 PowerShell)

```powershell
schtasks /Query /TN OnePad                      # 로그온 작업
Get-Process onepad                              # 상주 확인
Get-Content "$env:LOCALAPPDATA\OnePad\onepad.log" -Tail 30   # 'virtual controller enumerated', 'claimed by host', 'cloak ON' 이 보여야 함
& "C:\Program Files\Nefarius Software Solutions\HidHide\x64\HidHideCLI.exe" --cloak-state   # Steam 실행 중이면 --cloak-on
Get-PnpDevice -PresentOnly | ? InstanceId -match 'VID_28DE'  # 가상 Deck 장치들(복합, HID 3개, COM)
Select-String D:\Steam\logs\controller.txt -Pattern 'device opened|XInput Controller' | Select -Last 4
#   → "opened for index 15" 만 있고 "XInput Controller #1 ... index 0" 이 없어야 정상
```

## 4. 함정 모음 (2026-11-05 ~ 07에 실제로 겪은 것)

- **Steam은 시작 1초 안에 실제 패드를 잡고 그 뒤에 숨겨도 놓지 않는다.** 그래서 Steam이 (재)시작하는 순간 HidHide 숨김이 이미 켜져 있어야 한다. 2026-11-07부터 `[hidhide] mode=always`: 컨트롤러가 꽂혀 있는 한 항상 숨기고 OnePad가 꺼져도 풀지 않는다(`--restore`/`--uninstall`만 품). IG_00/IG_01 두 HID 노드와 USB IG 노드까지 모두 숨긴다. 비Steam XInput 게임은 Steam에 비Steam 게임으로 넣어서 쓴다. 그래도 3D One이 Steam에 보이면 Steam 재시작.
- **Steam의 "Xbox 컨트롤러에 Steam 입력 사용" 설정(localconfig.vdf `SteamController_XBoxSupport=0`)은 무시된다.** 믿지 말 것. 해결은 HidHide뿐.
- **Steam을 관리자 셸에서 띄우지 말 것.** Steam과 게임이 관리자 권한으로 떠서 Steam Input이 깨진다. 띄워야 하면 `explorer.exe "D:\Steam\steam.exe"`.
- **HidHide를 지우지 말 것.** 2026-11-06에 지웠다가 Steam 게임 2P 중복이 재발해 되돌렸다. Azahar 멈춤은 HidHide 탓이 아니었다.
- **Azahar 멈춤(창 없이 프로세스만)** = SDL2의 Windows.Gaming.Input 초기화 교착. 가상 Deck을 SDL이 열거나(닫고 바로 재실행), Steam 오버레이 훅이 붙으면 발동. `azahar-launch.exe`로 실행하면 안 난다. `azahar_log.txt` 0바이트는 지표가 아니다. 다른 SDL 에뮬레이터(Dolphin, PCSX2…)도 같은 증상이면 `tools\sdl-launch.cpp`의 `azahar.exe`만 바꿔 빌드.
- **Azahar는 Steam에서 실행.** Steam이 켜진 동안 실제 패드는 숨겨져 있으므로 바로가기로 직접 띄우면 컨트롤러가 없다.
- **shortcuts.vdf/localconfig.vdf 편집은 Steam 완전 종료 후에만.** 켜진 채 고치면 종료 시 덮어쓴다. 항상 백업.
- **Prd.exe(Gear 설정 앱)가 켜져 있으면** OnePad의 펌웨어 쓰기가 -11로 실패한다. 닫을 것.
- **Intel Arc + Azahar는 Vulkan.** OpenGL은 죽는다. 게임별 `config\custom\*.ini`가 전역 설정을 조용히 이긴다.
- usbip vhci가 "device in use"인데 열거가 안 되면 `pnputil /restart-device ROOT\USB\0000` (OnePad가 자동 수행).

## 5. 파일 지도

```
OnePad\
  Setup-OnePad.ps1        ← 재설치 원샷 (이 문서의 2절)
  재설치-가이드.md          ← 이 문서
  README.md               ← 설계/설정 전체 문서 (ini 키, 라우팅, 문제 해결 메모)
  bin\onepad.exe          ← 실행본 (로그온 작업이 이 경로를 가리킴)

  bin\sapjoyapis.dll      ← 벤더 SDK 사본 (원본: C:\Program Files (x86)\Gear\Settings)

  config\firmware-backup.ini ← 원본 펌웨어 값 (복원용)
  installer\              ← USBip-0.9.8.1-x64.exe, HidHide_1.5.230_x64.exe, azahar-windows-msys2-2126.1.zip

  tools\sdl-launch.cpp    ← 래퍼 소스
  src\                    ← OnePad 소스 (빌드: build.ps1, LLVM-MinGW winget MartinStorsjo.LLVM-MinGW.UCRT)
  Uninstall-OnePad.ps1    ← 제거 (onepad.exe --uninstall)
```
